## О проекте

**Controller for computer** — Telegram-бот, превращающий чат в удалённый пульт для Windows-ПК.

Через Telegram можно выполнять системные команды на компьютере, получать снимки экрана и веб-камеры, открывать ссылки, управлять мультимедиа, мышью и клавиатурой.

![Главное меню](https://user-images.githubusercontent.com/59653793/180392538-ba1c6a0b-73d7-45dd-bc11-65e15aaf0f31.png)

## Возможности

### 💤 Питание и экран

- Перевод компьютера в спящий режим.
- Переход в спящий режим по таймеру.
- Отключение экрана.
- Выключение компьютера.

### 📷 Экран и веб-камера

- Создание снимка экрана и отправка его в Telegram.
- Получение снимка с подключённой веб-камеры.

### 🌐 Браузер

- Открытие на компьютере ссылки, отправленной боту.
- Сохранение полученной ссылки в текстовый файл.

![Управление браузером](https://user-images.githubusercontent.com/59653793/180392809-a6625191-6ed6-49e8-9d41-131503a9a54e.png)

### 🎵 Музыка и видео

- Регулировка громкости.
- Пауза и продолжение воспроизведения.
- Переключение треков.
- Управление видео: пауза, перемотка, полноэкранный режим и громкость.

![Управление мультимедиа](https://user-images.githubusercontent.com/59653793/180392923-36021c42-2722-4011-8f8c-40d2603a7f4c.png)

### 🖱️ Мышь и клавиатура

- Перемещение указателя, включая ускоренное перемещение.
- Левый и правый клик, двойной клик.
- Прокрутка.
- Переключение вкладок.
- Управление через `Alt` / `Tab`.
- Быстрый переход к управлению музыкой и видео.

![Управление мышью](https://user-images.githubusercontent.com/59653793/180392705-0ce286f3-ed90-4608-b54f-3c7dc0f43acc.png)

### 💬 Текстовые сообщения

- Создание локального `.txt`-файла.
- Запись полученных через Telegram сообщений в файл во время работы бота.

### 🗄️ База данных

В проекте сохранён отдельный модуль для работы с SQLite: создание таблицы, добавление данных и чтение сохранённых записей. Его использование требует отдельной настройки и не является основным сценарием управления ПК.

## Технологии

- **Python**
- **aiogram** — Telegram-бот и FSM-сценарии
- **OpenCV** — работа с веб-камерой
- **PyAutoGUI**, **keyboard**, **pynput** — управление экраном и устройствами ввода
- **SQLite** — экспериментальный модуль хранения данных
- **PowerShell / Windows Batch** — системные команды Windows

## Статус проекта

Проект больше не развивается активно и сохранён в исходной архитектуре как один из ранних pet-projects.

Репозиторий оставлен публичным как часть истории профессионального развития и как пример автоматизации взаимодействия с Windows через Telegram.
